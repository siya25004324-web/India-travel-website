# India-travel-website
Majestic India: A travel website highlighting India’s wonders, created using only HTML.
#Description
This project is a static travel website built using only HTML. It showcases India’s famous destinations with images, ordered and unordered lists, tables, and descriptive paragrahs-
#Features
1.)Home page with welcome message and pictures of incredible India
2.)Images of travel destinations opened in hyperlink
3.)Ordered Lists of places to visit in India
4.)Tables for Travel packages displaying destination,duration and price
5.)Paragraphs highlighting culture and heritage
6.)Contact section
#How to View
Clone or download this repository
Open the assignment.html file in your browser
-->That’s it—no setup required!
